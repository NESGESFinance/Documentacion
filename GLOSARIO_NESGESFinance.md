# Glosario Institucional NESGESFinance v3.1

**Lema:** “Y a tu prójimo como a ti mismo”  
**Tagline:** “Tokenización con Propósito”

## Propósito

Este glosario establece definiciones uniformes para los materiales públicos, técnicos, jurídicos y comunicacionales de NESGESFinance.

Las definiciones de este documento no constituyen asesoría legal, financiera, tributaria, contable ni de inversión. Ante cualquier conflicto entre este glosario, un documento jurídico formal o un registro verificable en Bitcoin, prevalecerá el documento jurídico aplicable o el registro on-chain, según corresponda.

## A

### Activo de utilidad técnica

Activo digital diseñado para habilitar interacciones, coordinación o funciones técnicas dentro de un ecosistema. En el contexto institucional v3.1, esta expresión se usa para describir a NGF•BTC•AM y no implica acciones, participación societaria, dividendos, intereses, derechos de crédito, retorno financiero ni garantía de liquidez.

### AML

Sigla de *Anti-Money Laundering* o prevención de lavado de activos. Comprende controles, procedimientos y análisis orientados a identificar, prevenir y reportar operaciones potencialmente vinculadas con actividades ilícitas, conforme a la normativa que resulte aplicable.

### API

Sigla de *Application Programming Interface*. Interfaz mediante la cual un sistema puede intercambiar información o solicitar funcionalidades a otro sistema de forma programática. Una API solo debe anunciarse como disponible si su implementación, documentación y controles de seguridad son verificables.

## B

### Backend

Componente no visible de una aplicación que procesa reglas de negocio, autenticación, bases de datos, integraciones, permisos y otras operaciones de servidor. Un sitio estático no sustituye un backend seguro para KYC, tratamiento de datos personales o funciones transaccionales.

### Bitcoin L1

Capa base de la red Bitcoin. Se utiliza como red de registro y liquidación descentralizada. Las transacciones confirmadas en esta capa son finales conforme a las reglas del protocolo y no pueden ser revertidas unilateralmente por NESGESFinance.

### Bitcoin L2

Expresión general para sistemas que operan relacionados con Bitcoin, pero fuera de la capa base, con el propósito de ampliar determinadas capacidades. Su existencia, integración y estado deben comunicarse con precisión como implementados, en desarrollo, planificados o no disponibles públicamente.

## C

### CFT

Sigla de *Countering the Financing of Terrorism*, referida a medidas orientadas a prevenir la financiación del terrorismo.

### Clave privada

Credencial criptográfica que permite autorizar operaciones asociadas a una dirección o activo digital. No debe compartirse, enviarse por formularios, almacenarse en repositorios ni entregarse a terceros.

### Consentimiento informado

Manifestación libre, específica, informada e inequívoca mediante la cual una persona acepta un tratamiento de datos o una condición aplicable. Debe ser verificable, registrable y revocable cuando la normativa aplicable lo permita.

### Custodia

Control o administración de claves privadas o activos digitales en nombre de una persona. No debe afirmarse que existe custodia institucional, multifirma, recuperación de activos o administración de claves sin evidencia técnica, contractual y operativa comprobable.

## D

### Datos personales

Información que identifica o puede identificar a una persona natural, directa o indirectamente. Incluye, entre otros, nombres, documentos de identidad, correo electrónico, datos de contacto, imágenes, datos biométricos y ciertos identificadores técnicos.

### Debida diligencia

Proceso de verificación, análisis y evaluación de una persona, entidad, proyecto o transacción. Su alcance debe definirse conforme al riesgo, el objetivo del proceso y la normativa aplicable.

### Divisibilidad

Parámetro que determina la capacidad de fraccionar una unidad de un activo digital. NGF•BTC•AM tiene divisibilidad `0`; sus unidades no se fraccionan mediante decimales.

## E

### En desarrollo

Estado comunicacional reservado para una función cuya implementación está en curso, pero que no está disponible de forma funcional, segura y verificable para el público.

### Evidencia verificable

Prueba documental, técnica, jurídica u on-chain suficiente para respaldar una afirmación pública. Puede consistir en registros en blockchain, código publicado, informes, instrumentos jurídicos, pruebas funcionales o documentación vigente, según el tipo de afirmación.

## F

### Fase de postulación

Etapa inicial mediante la cual se recibe información para evaluar una iniciativa. La postulación no constituye aceptación, aprobación, financiamiento, emisión de tokens ni compromiso contractual.

### Formulario digital

Interfaz para recopilar información de usuarios. Si recoge datos personales, debe contener aviso de privacidad, finalidad, base de tratamiento, consentimiento cuando corresponda y medidas de seguridad acordes al riesgo.

## G

### GitHub Pages

Servicio de publicación de sitios estáticos desde un repositorio GitHub. Es adecuado para contenidos públicos, documentación y páginas institucionales. No debe utilizarse para almacenar datos KYC, secretos, claves privadas, documentos sensibles o lógica crítica de backend.

### Gobernanza consultiva

Mecanismo de participación que recoge opiniones, propuestas o preferencias de una comunidad, sin que ello implique por sí mismo decisiones societarias, obligaciones legales o efectos vinculantes.

## K

### KYC

Sigla de *Know Your Customer* o “conozca a su cliente”. Conjunto de procesos de identificación y verificación aplicables según el servicio, nivel de riesgo y marco regulatorio correspondiente.

## L

### Lightning Network

Red de canales de pago asociada al ecosistema Bitcoin. Solo debe presentarse como integrada, operativa o disponible cuando existan pruebas técnicas y controles de seguridad que lo acrediten.

### Lista restrictiva

Registro público o privado utilizado para controles de cumplimiento, que puede incluir sanciones, personas expuestas políticamente u otras categorías definidas por autoridades u organizaciones competentes.

## M

### Mainnet

Red principal y operativa de un protocolo blockchain. Se distingue de entornos de prueba o desarrollo.

### Mempool

Conjunto de transacciones de Bitcoin que han sido difundidas a la red pero aún no han sido confirmadas en un bloque.

### No disponible públicamente

Estado comunicacional reservado para una función que no se encuentra habilitada para uso público, aunque pueda estar siendo evaluada, diseñada o desarrollada internamente.

## O

### OFAC

Sigla de *Office of Foreign Assets Control*. Organismo de Estados Unidos que administra determinados programas de sanciones. La referencia a listas OFAC no sustituye el análisis jurídico ni los controles aplicables en cada caso.

### On-chain

Información, operación o registro que existe y puede verificarse directamente en una blockchain.

### Ordinals

Protocolo o convención utilizada en Bitcoin para asociar inscripciones y artefactos digitales a satoshis. Su uso no altera la necesidad de cumplir requisitos técnicos, jurídicos, de propiedad intelectual y de comunicación responsable.

## P

### Planificado

Estado comunicacional reservado para una idea, objetivo o función contemplada para el futuro, sin que implique compromiso de desarrollo, fecha determinada ni disponibilidad futura garantizada.

### Política de privacidad

Documento que informa cómo se recolectan, utilizan, conservan, protegen y, cuando aplique, comparten datos personales, así como los mecanismos para ejercer derechos conforme a la normativa aplicable.

### PSBT

Sigla de *Partially Signed Bitcoin Transaction*. Formato que permite construir y firmar una transacción Bitcoin en una o varias etapas. El usuario debe verificar siempre monto, comisión, activos involucrados y dirección de destino antes de firmar.

## R

### Reg D 506(c)

Referencia a una posible exención regulatoria estadounidense. No constituye por sí misma autorización, oferta, recomendación ni evidencia de que una estructura determinada esté disponible o aprobada.

### Reg S

Referencia a una posible exención regulatoria estadounidense para ciertas ofertas fuera de Estados Unidos. No constituye por sí misma autorización, oferta, recomendación ni evidencia de que una estructura determinada esté disponible o aprobada.

### Riesgo de liquidez

Posibilidad de no poder comprar, vender, transferir o intercambiar un activo a un precio determinado, en un plazo determinado o en absoluto.

### Riesgo regulatorio

Posibilidad de que cambios normativos, regulatorios, tributarios o de interpretación jurídica afecten el uso, transferencia, tratamiento o valor de activos digitales.

### Runes

Protocolo asociado con Bitcoin para la inscripción y gestión de activos fungibles. La información sobre una Rune debe contrastarse con registros on-chain verificables.

### RWA

Sigla de *Real World Assets* o activos del mundo real. Expresión usada para referirse a iniciativas o activos vinculados con actividades, bienes o derechos fuera de la blockchain. Una referencia a RWA no equivale automáticamente a titularidad, garantía, valor mobiliario, respaldo, custodia ni derecho económico para los tenedores de un token.

## S

### Seed phrase / frase semilla

Conjunto de palabras que permite recuperar el control de una billetera digital. Debe mantenerse bajo control exclusivo de su titular. Nunca debe compartirse con NESGESFinance, colaboradores, soporte, formularios o repositorios.

### SPV

Sigla de *Special Purpose Vehicle* o vehículo de propósito específico. Entidad creada o utilizada para una finalidad definida. Toda referencia pública a un SPV debe corresponder a una entidad y documentación efectivamente formalizadas.

### Seguridad por diseño

Enfoque de desarrollo que incorpora controles de seguridad desde la planificación de una solución, en lugar de añadirlos únicamente después de su puesta en producción.

## T

### Taproot

Actualización de Bitcoin que habilita determinadas mejoras de privacidad, eficiencia y expresividad en scripts. La sola referencia a Taproot no prueba una integración funcional concreta.

### Taproot Assets

Protocolo asociado a la emisión y transferencia de activos sobre infraestructura compatible con Taproot. Debe presentarse como implementado únicamente cuando la funcionalidad sea demostrable y esté disponible bajo condiciones de seguridad verificables.

### Términos de uso

Condiciones que regulan la navegación, acceso y utilización de los sitios, aplicaciones, interfaces y servicios del Ecosistema.

### Tokenización

Proceso técnico y jurídico mediante el cual se representa, registra o coordina información, derechos o funcionalidades mediante tecnología digital. La tokenización no convierte automáticamente un activo en líquido, regulado, garantizado o apto para inversión.

### Trust / fideicomiso / patrimonio autónomo

Estructura jurídica cuya existencia, alcance, partes, activos, reglas y obligaciones dependen de un instrumento formal aplicable. No debe afirmarse que existe una estructura de esta naturaleza si no ha sido formalizada y documentada.

## W

### Wallet / billetera

Herramienta que permite visualizar direcciones y, según su modalidad, gestionar credenciales criptográficas para interactuar con una blockchain. Una interfaz de wallet no debe ser presentada como custodial, no custodial, auditada o plenamente operativa sin evidencia técnica correspondiente.

## Principio de lenguaje institucional

Todo contenido público debe utilizar una de las siguientes clasificaciones:

- **Implementado:** existe, es verificable y está disponible bajo las condiciones comunicadas.
- **En desarrollo:** su construcción está en curso y no debe presentarse como disponible.
- **Planificado:** existe como objetivo futuro y no debe implicar compromiso o fecha garantizada.
- **Conceptual:** describe una posible estructura, diseño o hipótesis aún no formalizada.
- **No disponible públicamente:** no está habilitado para el público.

## Denominación de marca

La denominación institucional autorizada es **NESGESFinance**.

No se debe utilizar ninguna denominación distinta que pueda generar confusión de marca, jurídica, técnica o comunicacional.
